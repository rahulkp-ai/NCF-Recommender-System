# Kubernetes manifests (reference scaffolding, not the near-term deployment path)

The primary deployment target for this project is a **free-tier PaaS**
(Render/Railway + Vercel) — see `docs/deployment/README.md`. This
directory exists as reference scaffolding for a future scale-up beyond
what a single-node PaaS deployment can handle.

Nothing here is currently applied to a running cluster.
